# Getting help

- **Questions and setup help:** ask in
  [Discussions](https://github.com/somejavadev/electric-fence/discussions).
  Someone may already have asked, so search first.
- **Something isn't working:** open a
  [bug report](https://github.com/somejavadev/electric-fence/issues/new/choose).
  Include the Home Assistant and Electric Fence versions, your install type,
  and the steps that lead to the problem. A diagnostics download helps most:
  **Settings** > **Devices & services** > **Electric Fence** > **⋮** >
  **Download diagnostics**.
- **A security problem:** report it privately, as the
  [security policy](SECURITY.md) explains. Don't post it in an issue or
  discussion.

Before posting logs, screenshots or diagnostics, remove IP addresses,
usernames and host names you don't want to share.

Electric Fence is maintained in spare time, so replies can take a few days.
