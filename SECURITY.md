# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private advisories:
[Report a vulnerability](https://github.com/somejavadev/electric-fence/security/advisories/new).

Don't open a public issue for a security problem. Include the Home Assistant
version, the Electric Fence version, and steps to reproduce. You can expect a
first reply within a few days.

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |
